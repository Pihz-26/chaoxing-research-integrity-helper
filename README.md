# 超星慕课《科研诚信与学术规范》学习脚本

用于超星慕课《科研诚信与学术规范》的浏览器用户脚本，集成参考题库，提供视频自动播放、视频中途弹题处理、课后题自动答题与提交，以及完成后自动继续下一节的功能。

本项目基于 [JackZxj/auto-chaoxing-mooc](https://github.com/JackZxj/auto-chaoxing-mooc) 的脚本思路和基础版本进行改进。感谢原作者提供基础脚本和题库整理入口。

> 题库不完整，答案也不保证全部正确。匹配不到可用答案时，脚本会随机选择一个选项，因此有时无法及格，需要自行检查并修改答案。

## 功能与运行流程

- 自动播放当前视频。
- 处理同一视频中先后出现的多道单选弹题，逐项尝试，每次弹题独立记录尝试次数。
- 视频结束后点击“下一节”，进入课后答题界面。
- 从内置题库匹配答案，支持精确匹配、部分自定义字体混淆题目的约束还原，以及题干片段和相似文本匹配。
- 存在多个候选时优先使用得分较高的可用题库记录；仍无可用答案时随机选择一项。
- 填写后点击页面“提交”，再点击“确认提交？”弹窗内的“提交”，等待平台显示完成后进入下一节并继续播放。
- 提供开始、停止、页面诊断导出按钮；面板会显示片段匹配和随机作答数量。

完整流程：

```text
播放视频 → 逐一处理视频弹题 → 视频结束 → 下一节
→ 课后题答题 → 页面提交 → 弹窗内提交 → 等待完成
→ 下一节 → 播放下一个视频
```

## 题库来源

参考题库来自 [CSDN博客－吴成伟0122：《科研诚信与学术规范》参考答案最新版](https://blog.csdn.net/qq_42859864/article/details/88608359)，通过基础仓库提供的 `answer.html` 整理为脚本内置数据。

题库与当前课程题目虽然不完全相同，但大部分题目可以找到对应参考，基本能够满足已有题目的匹配需求。脚本已经集成题库，无需另外下载、导入题库或配置答题 API。

当前内置 565 条可提取的文字记录，包含重复题干，不等于 565 道不重复题目。其中 28 条明确标注“正确答案”，537 条仅标注“我的答案”；默认均用于匹配。图片形式的补充题尚未收录为文字答案，参考答案未逐题独立核实。

## 在 Edge 脚本猫中使用

1. 在 Microsoft Edge 中安装并启用“脚本猫”（ScriptCat）扩展。
2. 打开本仓库的 [chaoxing-research-integrity.user.js](./chaoxing-research-integrity.user.js)，点击 **Raw**，复制全部脚本内容。
3. 打开脚本猫，新建脚本，替换默认内容，粘贴复制的完整脚本，保存并启用。
4. 如果安装过旧版本，先停用旧脚本，避免同时运行。
5. 打开超星慕课《科研诚信与学术规范》的章节学习页面，刷新页面，在右上角面板点击“开始”。
6. 若浏览器阻止自动播放，手动播放一次视频，再点击“开始”。点击“停止”可以停止后续自动操作。

无需安装 Node.js，不需要编译，也不需要单独导入题库。

## 匹配不到答案时

脚本按以下顺序尝试：

1. 精确匹配题干及选项。
2. 对带有 `.font-cxsecret` 标记的部分题目，结合内置题库进行字符替换约束还原。
3. 按共有文字片段或相似题干选择可用候选，并匹配选项文字。
4. 仍无法找到可用答案时随机选择一个选项；同一道题的随机结果在当前页面运行期间保持不变。

**片段匹配和随机作答可能答错，不保证及格。** 若分数不够，请自行检查题目和参考答案，修改答案或补充脚本内的题库数据。多选题在随机兜底时也仅选择一项，不保证选全。

## 配置与诊断

脚本顶部的 `CFG` 可调整以下设置：

| 设置 | 默认值 | 作用 |
| --- | --- | --- |
| `usePersonalAnswers` | `true` | 允许使用题库中仅标注“我的答案”的记录 |
| `autoSubmit` | `true` | 匹配并填写后自动提交；改为 `false` 可先人工检查 |
| `trialVideoSingle` | `true` | 对视频中途的单选弹题逐项尝试 |

若出现卡住、无法识别弹窗或页面控件的情况，可点击“导出页面诊断”，查看题干、选项、匹配方式和弹窗识别结果。诊断保存在本机，不会自动上传。

## 适配范围与验证状态

- 针对上述课程和当前超星章节学习页面设计，不保证其他课程、学校版本或页面改版后通用。
- 视频弹题目前按可逐项尝试的单选题处理，不枚举多选组合。
- 课后题以单选、判断和部分多选题为主；填空题、简答题、分页试卷不在当前支持范围。
- 字体处理采用已有题库约束还原，不是通用字体解码器；文字差异较大时会落到片段匹配或随机兜底。
- 已进行语法检查，以及多次视频弹题、任务切换、两阶段提交、自定义弹窗、实际乱码样例和宽松匹配的本地检查；未完成所有页面版本和整个课程的端到端验证。
